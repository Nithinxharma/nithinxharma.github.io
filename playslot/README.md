# PlaySlot Jaipur — PS5 Rental Website

Premium responsive front-end concept for a Jaipur City PS5 rental service.

## Pricing configured from your instructions
- PS5: ₹700 per day
- Extra controller: ₹200 per day, each
- Durations: 1, 2, 5 and 30 days
- Curated 7–8 game set included (sample game names need your confirmation)
- Personal game request: additional charge, quoted manually
- Permanent game purchase: enquiry only
- Delivery date, preferred time slot, customer contact and Jaipur address
- UPI, card or cash preference captured (no payment gateway connected)

## Before launch
1. PlaySlot Jaipur is a temporary brand name. Confirm/change it.
2. Replace sample game titles with the real games you provide.
3. In `app.js`, replace `https://wa.me/?text=` with `https://wa.me/91YOURNUMBER?text=` (digits only, including country code).
4. Confirm serviceable Jaipur localities, delivery charges, security deposit, late fee, damage/loss and cancellation rules.
5. This is a front-end demo: no live inventory, admin dashboard, payment collection or stored leads. Slot selection is a preferred request and requires manual confirmation.

# SEO & lead-generation setup

## Included in this build
- Search-focused title, description, canonical URL, robots directives and social sharing metadata.
- Person and WebSite structured data (JSON-LD).
- `robots.txt`, `sitemap.xml` and a lightweight SVG favicon.
- Search-intent sections for software/Android opportunities, freelance projects and open-source collaboration.
- FAQ content written for visitors, not keyword stuffing.
- Enquiry form that opens the visitor's email application. It does not transmit or store form data on a server.
- WhatsApp contact link and direct email / LinkedIn / GitHub links.

## Required after deployment
1. Open Google Search Console: https://search.google.com/search-console/
2. Add the URL-prefix property `https://nithinxharma.github.io/` and complete verification. A GitHub Pages URL-prefix property may be verified using an HTML file or meta tag; use the exact method Search Console offers.
3. Submit `https://nithinxharma.github.io/sitemap.xml` in Search Console.
4. Inspect the homepage URL and request indexing after the deployed page is publicly accessible.
5. Check the Enhancements / structured data reports and URL indexing report periodically.
6. Add real project repository links, original project screenshots, detailed case studies and a downloadable CV when verified. These are stronger long-term search assets than repeated keywords.

## Ranking reality
No implementation can guarantee the first Google result. Search visibility depends on competition, search intent, external references, site history, content quality and user demand. This build improves technical foundations; it does not promise a ranking or traffic volume.

## Lead handling
The form uses `mailto:` and depends on the visitor having an email app configured. WhatsApp is the alternative. For server-side lead storage, analytics, CRM integration or spam protection, choose and configure a provider deliberately; none is silently added here.

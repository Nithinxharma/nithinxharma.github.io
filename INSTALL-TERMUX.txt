TERMUX INSTALL

1. Download abhishek-portfolio-apple-editorial.zip into your phone's Download folder.
2. Run:

cd ~/portfolio/abhishek-portfolio
mkdir -p ~/portfolio-apple-update
unzip -o /sdcard/Download/abhishek-portfolio-apple-editorial.zip -d ~/portfolio-apple-update
cp -r ~/portfolio-apple-update/abhishek-portfolio/. .
rm -rf ~/portfolio-apple-update

3. Verify:
cat BUILD-VERSION.txt

4. Publish:
git add .
git commit -m "Redesign portfolio with minimal editorial system"
git push origin main

If your repository folder is different, replace ~/portfolio/abhishek-portfolio with your actual local website folder. If unzip reports errors, stop before running cp or git commands.

PORTFOLIO STORY V2 — TERMUX INSTALL

1. Download the ZIP to your phone (usually /sdcard/Download).
2. Run these commands. They copy the ZIP ROOT files into your existing site folder.

cd ~/portfolio/abhishek-portfolio
mkdir -p backup-before-story-v2
cp -r index.html styles.css script.js README.md CONTENT-TO-VERIFY.md assets backup-before-story-v2/ 2>/dev/null || true
mkdir -p /tmp/portfolio-story-v2
unzip -o /sdcard/Download/abhishek-portfolio-story-v2.zip -d /tmp/portfolio-story-v2
cp -r /tmp/portfolio-story-v2/. .
rm -rf /tmp/portfolio-story-v2

3. Confirm the new build is present:
cat BUILD-VERSION.txt
grep -n 'story-v2-20261030' index.html

4. Publish:
git status
git add index.html styles.css script.js BUILD-VERSION.txt INSTALL-TERMUX.txt assets README.md CONTENT-TO-VERIFY.md
git commit -m "Publish portfolio story rebuild v2"
git push origin main

If Git says there is nothing to commit, check that you are in the correct repository folder and that the downloaded ZIP was extracted.

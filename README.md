# Abhishek Sharma — Portfolio

A dark, narrative-led portfolio designed as a guided journey rather than a conventional collection of cards.

## Deploy on GitHub Pages

1. Extract the `abhishek-portfolio` folder.
2. Upload the contents of this folder to the root of the GitHub repository used for `nithinxharma.github.io`.
3. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Wait for the deployment, then open `https://nithinxharma.github.io`.

The site is static HTML/CSS/JavaScript. It requires no build step and no API key. The GitHub profile section reads public data from GitHub's unauthenticated API; it can temporarily fail when GitHub rate-limits requests.

## Files

- `index.html` — narrative portfolio content
- `styles.css` — responsive styling, transitions and reduced-motion support
- `script.js` — navigation, scroll progress, reveal animations and public GitHub data
- `assets/abhishek-portrait.jpg` — selected hero portrait
